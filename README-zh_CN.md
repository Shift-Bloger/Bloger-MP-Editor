# 微信公众号编辑器（Uyghur）

基于 Vue 3 + Tiptap 的微信公众号文章排版编辑器，提供经典工具栏、手机预览与深色模式适配。

简体中文 | [English](./README.md)

## 功能特性

- 手机预览区：窗口宽度较小时自动收起到左侧边栏，可点击侧边按钮再次展开
- 深色模式：覆盖编辑器页面与 Ant Design Vue 的弹窗/下拉（Modal/Popover）
- 经典工具栏：标题/字体/对齐/列表/表格/颜色/代码块/查找替换等
- 媒体插入：图片 / 视频 / PDF

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
