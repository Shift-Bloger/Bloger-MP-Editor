# WeChat MP Editor (Uyghur)

A WeChat Official Account article editor built with Vue 3 and Tiptap, with a live preview panel, a classic toolbar, and dark mode support.

English | [简体中文](./README-zh_CN.md)

## Features

- Live preview panel (auto-hide into left sidebar on small screens)
- Dark mode (covers editor UI and Ant Design Vue modals/popovers)
- Classic toolbar (headings, fonts, alignment, lists, tables, colors, code blocks, find/replace, etc.)
- Media insertion (image / video / PDF)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
